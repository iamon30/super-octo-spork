1. The 3D Modeling Workspace

🎬 Video: Workspaces 0:44 • Visual styles 3:07 • Viewports 10:10

A solid has volume, mass and faces/edges; a 2D drawing only has lines. Mechanical parts (shafts, brackets, housings) are modeled as solids so they can be viewed from any angle, measured, and turned into drawings.

  • Switch workspace: click the gear icon (bottom right) → 3D Modeling.
  • Ribbon tabs: Home (Modeling, Mesh, Solid Editing, Draw, Modify, Coordinates, View panels), Solid, Surface, Mesh, Visualize.
  • ViewCube (top right) – click faces/corners to change view; Navigation Bar – Pan, Zoom, Orbit, SteeringWheel.
  • Grid (F7) & Ortho (F8) & Object Snap (F3) help place points accurately.
  • Viewports: split Model space into 2–4 views (Top, Front, Right, Isometric) to see the part from many sides at once.

Visual styles: 2D Wireframe • Wireframe (all edges) • Hidden (hidden lines removed) • Realistic (materials) • Shaded • Shaded with Edges • Conceptual • X-ray.

Try it: drag the cube to orbit, scroll to zoom — the same idea as the ViewCube.

2. User Coordinate System (UCS)

🎬 Video: UCS & viewpoints 4:04 • Draw on a face 7:34 • Dynamic UCS 9:17

WCS (World Coordinate System) is fixed. The UCS is a movable copy you place wherever you need to draw. Everything you draw lies on the XY plane of the current UCS, and Z is the height.

  • Right-hand rule: thumb = X, index finger = Y, middle finger = Z. Curling your fingers from X to Y shows the positive rotation.
  • Command: UCS → options: Face (align to a solid's face), Origin (move), 3 point, X / Y / Z (rotate about an axis), World (back to WCS), Previous.
  • Dynamic UCS (toolbar button or F6): hover over a face and the UCS aligns automatically while you draw on it — no manual UCS needed.
  • UCS icon shows axis directions; a small box at its base means you are in the WCS.

Typical workflow: 1) UCS → Face → click the face. 2) Draw the circle/rectangle on that face. 3) Use PressPull or Extrude to add or cut material. 4) UCS → World to reset.

3. Primitive Solids

🎬 Video: Primitives 13:48 • Box 14:12 • Cylinder 14:53 • Cone 15:11 • Boolean ops 20:04

Primitives are ready-made basic solids found in Home ▸ Modeling or by typing the command.

SolidCommandInput neededMechanical examples
BoxBOXCorner + length, width, heightBase plate, block, V-block
CylinderCYLINDERCenter, radius/diameter, heightPin, shaft, bushing blank
ConeCONECenter, base radius, height (top radius optional)Lathe center, countersink, nozzle
SphereSPHERECenter + radiusBall bearing, knob
WedgeWEDGECorner + length, width, height (sloped face)Ramp, key/gib, stop
TorusTORUSCenter, torus (path) radius, tube radiusO-ring, ring, handle

Tips: Type @L,W,H or click points with Ortho on. For Torus, the tube radius must be smaller than the torus radius. Other primitives: Pyramid and Polysolid (wall-like solid from a path).

Boolean operations combine primitives into parts: UNION (join), SUBTRACT (cut one solid from another, e.g. drilling a hole), INTERSECT (keep the overlapping volume).

4. Extrude, Revolve, Loft, Sweep, PressPull

🎬 Video: PressPull 1:48 • Extrude 16:04 • PressPull 17:53 • Loft 24:45 • Revolve 29:19

These commands turn 2D profiles into 3D solids. The profile must be a closed object (circle, closed polyline, rectangle, region). Use PEDIT ▸ Join or REGION to close separate lines.

CommandHow it worksStepsBest for
EXTRUDE (EXT)Gives height to a profile, straight, along a path, or with a taper angleEXT → select profile → Enter → type height (or Path/Taper)Plates, flanges, brackets
REVOLVE (REV)Spins a profile around an axis (360° or less)REV → select half-profile → pick axis points → angleShafts, pulleys, bolts, bushings
LOFTBlends two or more cross-sections (optionally with guides/path)LOFT → pick sections in order → Enter → Enter (or options)Funnels, ducts, transitions
SWEEPMoves a profile along a path (can twist/scale)SWEEP → select profile → select pathPipes, springs, hooks, bent rods
PRESSPULL (PRESS)Pushes/pulls a bounded area or face; adds or removes materialPRESS → click inside area → move cursor/type distanceQuick bosses, pockets, holes

Choosing: straight height → Extrude • rotational part → Revolve • changing shape between sections → Loft • follows a curve → Sweep • quick edit on a face → PressPull.

Common mistakes: profile not closed • sections picked in the wrong order for Loft • path touching the profile plane incorrectly for Sweep • forgetting to set the UCS before drawing the profile.

📖 Key terms (glossary)
Solid3D object with volume, faces and edges.
PrimitiveBasic ready-made solid (box, cylinder, cone, sphere, wedge, torus).
ProfileClosed 2D shape used to create a solid.
PathLine/curve a profile follows (Sweep, Extrude along path).
Region2D closed area created from closed objects with REGION.
WCS / UCSFixed world axes / user-defined movable axes.
Boolean operationUnion, Subtract or Intersect of solids.
Orbit / Pan / ZoomRotate, slide and scale the view (not the model).
ViewportA window showing one view of the model.

✍️ Practice exercises
  1. Model a 100 × 60 × 10 mm base plate (BOX), then drill four Ø10 holes with CYLINDER + SUBTRACT.
  2. Draw a stepped shaft half-profile and REVOLVE it 360° about its centerline.
  3. LOFT a Ø60 circle to a 50 × 50 square 80 mm above it to make a transition duct.
  4. Draw a Ø10 circle and SWEEP it along an arc-and-line path to make a bent pipe.
  5. Use UCS ▸ Face on the top of a block, draw a rectangle, and PRESSPULL it down 5 mm to cut a pocket.
📌 Quick summary
  • Use the 3D Modeling workspace; navigate with wheel, Shift+wheel and the ViewCube.
  • Set the UCS so the XY plane matches the face you are drawing on.
  • Build basics with primitives and combine them with Union / Subtract / Intersect.
  • Convert closed profiles with Extrude, Revolve, Loft, Sweep; edit quickly with PressPull.
